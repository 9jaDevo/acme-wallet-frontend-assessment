# Transactions design

Use the **Figma design link attached to your invitation** as the visual source of truth.
It includes desktop and mobile Transactions screens, transaction details, loading/empty/error states,
and filter options. Inspect those frames for layout, spacing, typography and copy.

See [ASSIGNMENT.md](../ASSIGNMENT.md) for behaviour, time and submission requirements, and
[API.md](../API.md) for the data contract. Where the design and API leave a gap, ask us or document
a reasonable assumption in your PR.
